# data_enrichment 0.4.0 — Comparative Enrichment

This milestone adds provider-neutral benchmark and peer-group comparison primitives.

## Benchmark comparison

`BenchmarkComparisonEnricher` aligns target and benchmark daily observations by calendar date and derives:

- one-period excess-return series
- return and excess-return horizons
- beta
- correlation
- annualized tracking error
- information ratio

The benchmark record set and target record set are both included in derivation lineage.

## Peer comparison

`PeerReturnComparisonEnricher` accepts peer records through `EnrichmentContext.metadata["peer_records"]`. It derives target-vs-peer statistics for configured return horizons:

- peer count and observation count
- peer mean/median/minimum/maximum
- target percentile within the peer distribution
- excess versus peer median
- peer-distribution z-score

Peer comparison is descriptive. It does not rank securities as recommendations or perform prediction.

## Data contract

Both enrichers operate only on records already present in the enrichment context. They do not access external APIs. This keeps the source boundary in `data_collection` and the evidence semantics in `data_foundation`.
