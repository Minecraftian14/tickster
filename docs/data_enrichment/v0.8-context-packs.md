# v0.8 — Multi-resolution context packs

This milestone introduces bounded analytical context packs over existing enrichment outputs.

A context pack is **not** an LLM prompt and does not perform new calculations. It selects existing derived observations, series, and summaries into a configurable, deterministic view while retaining the original derived IDs for drill-down.

## Core ideas

- Full enrichment remains intact; pack selection is lossy only inside the pack.
- Section specifications select metrics/summaries by exact name or prefix.
- Series can be truncated by per-series and total point budgets.
- Tail selection is the default so the most recent observations survive bounded contexts.
- `as_of` can filter derived series points when they carry `available_at`.
- Pack metadata records limits, counts, omitted points, and whether selection was lossy.

## Built-in profiles

- `COMPACT_RESEARCH_CONTEXT`: small recent/weekly/monthly view.
- `MEDIUM_RESEARCH_CONTEXT`: broader bounded research view.
- `FULL_RESEARCH_CONTEXT`: larger bounded analytical view, still not a raw-data dump.

The package deliberately leaves language-model formatting, tokenization, RAG retrieval, and prompt construction to a later representation package.
