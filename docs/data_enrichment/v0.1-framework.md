# v0.1 Framework

## Responsibility

`data_enrichment` answers **what can be deterministically derived from canonical information?** It does not collect source data, redefine point-in-time semantics, or choose what an LLM should consume.

## Output hierarchy

```text
DerivedObservation  one value at one point in time
DerivedSeries       time-indexed derived values
DerivedSummary      compact descriptive aggregate
```

Every output carries `DerivationLineage`.

## Optional backends

- FinanceToolkit: broad financial-ratio/growth/profitability/valuation computation. The current PyPI release is 2.2.1 and its project describes 500+ transparent financial methods.
- QuantStats: optional portfolio/performance/risk computation backend boundary; integration comes after the framework milestone.
- pandas-ta-classic: optional technical-analysis backend boundary; current release is 0.8.32 and MIT licensed.

These are integration points only in v0.1. The package remains usable without them.
