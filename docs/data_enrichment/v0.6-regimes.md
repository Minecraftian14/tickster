# v0.6.0 — Regime and Historical-State Enrichment

This milestone turns long market histories into compact, descriptive state representations while retaining the full underlying history.

## Enrichers

- `regime.historical_state` — 1y/3y/5y/10y-style summaries using observation-count horizons, with shorter-history fallback.
- `regime.trend_state` — descriptive trend classification using moving-average relationships and slopes.
- `regime.volatility_state` — current realized volatility plus historical percentile and a low/normal/high descriptive state.
- `regime.extremes` — all-time high/low, distances, and elapsed time since extremes.
- `regime.persistence` — positive/negative-day fractions, current/max streaks, and time above a moving average.

All outputs are deterministic and descriptive. They do not make predictive claims.

## Context-size role

The enriched store can retain the full daily history. These summaries create compact long-horizon descriptors for later representation/context builders, so an LLM does not need to receive every raw bar to reason about long-term price behavior.

## Point-in-time behavior

The enrichers operate only on records visible through `EnrichmentContext`. Supplying `as_of` therefore reconstructs the historical state using only information visible at that point in time.
