# v0.9 — Enrichment Profiles & Dependency Planner

`data_enrichment` v0.9 introduces declarative enrichment profiles and a deterministic dependency planner.

## Responsibilities

- profiles describe requested enrichers and upstream capabilities
- the planner resolves transitive enricher dependencies
- capabilities already supplied by the caller are reused
- missing external capabilities are reported rather than fabricated
- ambiguous providers require an explicit provider preference
- dependency cycles are detected
- resolved plans can be executed independently of the planner

## Main API

```python
from data_enrichment import (
    ProfilePlanner,
    default_profile_registry,
    default_registry,
)

profiles = default_profile_registry()
planner = ProfilePlanner(default_registry(), profiles)
plan = planner.plan(
    "market_core",
    available={"price.close"},
)

assert plan.is_executable
print(plan.step_names)
```

## Capability planning

A capability can be supplied by `data_foundation`, another upstream system, or another enricher. When a capability has multiple providers, the planner refuses to guess. Supply a mapping such as:

```python
provider_preferences = {
    "market.return": "market.returns",
}
```

This avoids hidden backend/provider selection.

## Profiles

Existing profiles remain available as named packs. v0.9 adds `research_core`, a broad descriptive profile combining market, comparative, fundamental, ownership, event and regime enrichers.

Profiles are orchestration configuration, not LLM prompts. They do not define serialization or context budgets; that remains the job of context/representation layers.

## Reuse

The planner accepts `available` capabilities, so downstream callers can reuse existing results without rerunning an enricher. The resolved plan records effective capabilities and provider choices in metadata.

## Execution

`execute_plan()` executes a previously resolved plan and records the requested profile, planned enrichers, final capabilities and missing capabilities in the result metadata.
