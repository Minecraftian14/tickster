# data_enrichment 0.2.0 — Structural + Market Enrichment

This milestone expands the deterministic enrichment layer without introducing predictive or LLM behavior.

## Packs

- `market.returns`: one-period simple return, log return, cumulative return.
- `market.return_horizons`: 1/5/21/63/126/252-observation horizon returns plus cumulative/annualized return when available.
- `market.rolling_volatility`: annualized rolling realized volatility.
- `market.volatility_summary`: descriptive distribution and annualized volatility summary.
- `market.drawdown`: running drawdown series and maximum-drawdown summary.
- `market.moving_averages`: configurable simple moving averages and current distance from each average.
- `market.liquidity`: configurable-window average volume, traded value and delivery percentage, plus coverage ratios.
- `market.relative_performance`: benchmark-relative return series and summary; benchmark records are supplied through context metadata.
- `market.multi_resolution`: weekly/monthly return aggregations.

## Point-in-time semantics

Every enricher receives an `EnrichmentContext`. When `as_of` is present, visible input records are selected through `data_foundation` point-in-time semantics. The enrichment layer does not introduce another temporal model.

## Lineage

Every derived series/summary records its input canonical IDs and calculation metadata. When foundation `SourceObservation` objects are supplied to the context, observation and raw-artifact IDs flow through the lineage as well.

## Context-size philosophy

The full enriched store may be much larger than any LLM context. This milestone therefore produces both detailed series and compact summaries. A future representation package can choose the appropriate resolution without recomputing the underlying analytics.
