# data_enrichment v1.0 — Stable Contract

## Scope

`data_enrichment` v1.x transforms point-in-time-aware `data_foundation` records into deterministic analytical observations, series, summaries, and bounded context packs.

It does not collect external market data, make predictive trading decisions, or dictate an LLM representation format.

## Compatibility

- Package version: `1.0.0`
- Contract version: `1.0`
- Foundation compatibility: `data_foundation` `1.x`

Patch/minor releases within the `1.x` contract may add capabilities without changing the existing stable API semantics. A future major contract may remove or redefine stable surfaces only with an explicit migration.

## Stable surfaces

The machine-readable contract is exposed by `data_enrichment.contract`: `public_contract()`, `validate_public_contract()`, `is_compatible_contract()`, and `assert_compatible_contract()`.

## Guarantees

1. Derived outputs are deterministic unless explicitly documented otherwise.
2. Derivation metadata and evidence lineage are retained when inputs provide lineage references.
3. Point-in-time visibility is delegated to `data_foundation`.
4. Optional third-party computation backends remain optional.
5. Context packs select existing derived outputs and do not recalculate them.
6. Provider-specific data acquisition is outside this package.

## Versioning

`data_collection` remains an independent package and version stream. `data_enrichment` depends on the stable `data_foundation` contract rather than on source providers.
