# v0.7 Optional Computation Backends

`data_enrichment` treats third-party analytics libraries as calculation engines, not data sources. The caller supplies the data already collected and governed by `data_foundation`.

## FinanceToolkit

The adapter supports the ratio families currently exposed by FinanceToolkit: all ratios, efficiency, liquidity, profitability, solvency, and valuation. It accepts custom caller-supplied balance sheet, income statement, and cash-flow datasets and records `caller_supplied_only` in the result metadata. ## pandas-ta-classic

The adapter supports common technical indicators and strategies, including SMA, EMA, RSI, MACD, Bollinger Bands, ATR, ADX, OBV, stochastic, Williams %R, candlestick patterns, and the library's strategy interface. The current package documents 224 indicators/utilities and 62 native candlestick patterns, with no TA-Lib requirement for those native patterns. citeturn333774search0turn333774search1

## Design rule

No backend is allowed to become an upstream data source merely because the third-party library can download data itself. This keeps provider provenance and point-in-time semantics owned by `data_collection` and `data_foundation`.
