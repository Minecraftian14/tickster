# v0.1.0 — Canonical Foundation

Initial package for the post-collection foundation layer.

Implemented:

- canonical instrument identity + aliases
- temporal envelopes and point-in-time visibility
- source observation preservation
- numeric reconciliation findings
- provenance-carrying relationships
- explicit data-quality statuses
- company timelines
- collection-result ingestion/indexing
- canonical JSONL + manifest persistence
- isolated package versioning
