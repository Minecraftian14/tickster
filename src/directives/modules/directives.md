# Directives Module

## Purpose and Tools

`src/directives/` holds authoritative project specifications and context.
Start at [`index.md`](../index.md) to find the applicable directive.

## Placement and Boundaries

Keep directive files under this directory.
Use `decisions/` for durable design rationale.
Write concisely and precisely: keep sentences on separate source lines within a paragraph, avoid repeating context already established elsewhere, and link to the authoritative source.

## Ownership and Acceptance

Follow the [directive writing standard](../standards/directives.md) and keep each requirement in its authoritative location.
See [the module specification convention](directives.modules.md) when adding or revising module-family specs.
