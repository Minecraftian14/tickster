# Directives Module

This directory is the authoritative home for product requirements, architecture, ownership, module contracts, standards, and validation guidance.
Start with [`../index.md`](../index.md) to find the applicable specification.

Treat directives as version-controlled project artifacts.
Follow [the directive writing standard](../standards/directives.md), keep each requirement in its authoritative location, and use `decisions/` for durable design rationale.
