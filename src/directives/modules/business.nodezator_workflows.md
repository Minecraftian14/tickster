# `business.nodezator_workflows`

## Purpose and Tools

This directory stores Nodezator workflow documents that compose visual flows.
The workflow files are operational artifacts because they encode executable composition.

## Placement and Boundaries

Keep workflow documents under `src/business/nodezator_workflows/` in the format expected by Nodezator.
Use node definitions from `nodes_pack/` and preserve filenames or paths referenced elsewhere.
Coordinate composition changes with affected node definitions and experiment functions.

## Ownership and Acceptance

Treat workflow changes as human-reviewed or hybrid.
Confirm the workflow opens, references discoverable nodes, and retains intended graph connectivity.
