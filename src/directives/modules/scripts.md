# Project Scripts

## Purpose and Tools

Project scripts use XONSH.
`src/scripts/run.xsh` reads command definitions from the root `run.json`.

## Placement and Boundaries

Place project utility scripts under `src/scripts/` and follow the [XONSH standards](../standards/scripts.md).

## Ownership and Acceptance

Update existing command configuration when adding a command.
Exercise the affected command with representative arguments.
