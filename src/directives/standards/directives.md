# Directive Writing Standard

Directives are authoritative project artifacts.
Write requirements clearly, distinguish current observations from normative rules, and link to the directive that owns a rule rather than duplicating it.

When a paragraph contains multiple sentences, put each sentence on its own source line.
Use a single newline between sentences in the same paragraph, as in `Line one.\nLine two.`
Preserve paragraph breaks with a blank line, as in `Paragraph one.\n\nParagraph two.`

Use headings and lists to make requirements easy to scan.
Label examples as illustrative unless they are explicitly normative.
Do not turn an implementation detail or inference into a permanent rule without stating its basis and obtaining any required review.
